# Contributing

1. Use Node.js 20+.
2. Run `npm test` and `npm run check` before submitting a change.
3. Keep user data local by default; any external transfer requires explicit user consent and privacy documentation.
4. Never add decorative controls that do not perform an action.
5. Keep keyboard and visible-button alternatives for gesture interactions.
6. Update `OFFLINE_CAPABILITIES.md`, `PRIVACY.md` and `THIRD_PARTY_LICENSES.md` when behavior or dependencies change.
7. Avoid committing generated `dist/`, browser data, exported backups or secrets.
